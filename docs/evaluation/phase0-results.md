### 參數掃描（round-2 待辦 3，2026-09-08）

網格：starter ∈ {10, 20, 50} × 風險費 ∈ {3%/1%, 6%/2%} × deadbeat ∈ {5%, 15%, 30%}，400 agents × 84 天，baseline 情境。完整數據：`sim/out/sweep.csv`（18 cells）。工具：`python3 -m amcn_sim.sweep`。

**邊界發現：**

1. **G3（壞帳 ≤ 保險池）的通過邊界**：3%/1% 費率只撐得住 5% deadbeat；6%/2% 費率在 starter ≥20 時撐到 30% deadbeat。費率是有效槓桿，確認動態風險定價的必要性。
2. **反直覺：提高 starter credit 反而降低壞帳率**。30% deadbeat 下，starter 10→50 使壞帳率 5.27%→2.23%——因為流動性（結算量 5.4k→32.9k CC，6 倍）比壞帳絕對值長得快，違約損失被市場規模稀釋。「保守起始額度＝安全」的直覺在系統層面是錯的：太小的 starter 同時餓死市場和放大壞帳占比。
3. **G4（還債 <30 天）在 deadbeat ≥15% 時全網格 FAIL（36–42 天）**，不隨 starter 或費率變動——確認是人口結構效應，護欄應設在「違約率監控＋信用緊縮」而非費率。
4. **G5（成交率 ≥80%）全網格 PASS**（86.6–97.3%）。
5. **暫定建議參數**（帶入 Phase 1）：starter 50 CC＋風險費 6%/2%——在 30% deadbeat 壓力下 G3 仍 PASS（壞帳 2.05% < 保險 3.40%），結算量為 starter 20 方案的 ~3 倍。

### 結論

1. **F-1 已封閉。** 洗量從「信用槓桿」變成「信用毀滅」：同活躍度下，誠實 Agent 額度 60.9 CC vs 洗量 29.7 CC（賺得更多、信用只有一半）。第一輪 G2 的 FAIL 有一半是比較偏差——全體誠實平均被 33% 從未接單的純消費者拉低；正確基準是活躍度配對組（已改進 metrics）。
2. **F-2 部分封閉，且槓桿已驗證。** 預設費率下 high_default（15% 跑路）壞帳 434 > 保險池 253（G3 FAIL）；敏感度實驗把風險費加倍（6%/2%）後 G3 PASS（491 > 378、未覆蓋壞帳 0），結算量僅 −7%。**含義**：固定費率不夠，需整合架構規劃的動態風險定價（提案 C）——違約率上升時費率自動上調。預設值維持 3%/1%（避免冷啟動摩擦），動態調整列入協議設計。
3. **G4 的兩個 FAIL 是環境性質，不是機制缺陷。** expiry_cliff 的 32 天來自全網計費週期同步化（現實中自然錯開）；high_default 的 41.5 天來自 15% 人口消失拖慢信用循環。兩者都在費率實驗中不隨費率變動，屬人口結構效應。
4. **反作弊摩擦的代價可量測**：E_eff＋風險費使 baseline 結算量約 −7%、單一對手起家的新人賺信用變慢——這就是提案 C 評審警告的「反作弊 vs 冷啟動」張力，現在有了數字。

## 發現與處置

### F-1（紅）：混合洗量策略打穿 25% 多樣性折減

四情境中洗量 Agent 平均信用額度均高於誠實 Agent（最高 49.3 vs 17.9 CC）。機制：洗量對同時進行正常交易；洗量灌大貢獻總量後，「單一對手 ≤25% 總量」的天花板同步放大，假量對真信用形成槓桿。單元測試的「純洗量 < 純多樣」性質成立，但對混合策略無效。

**處置**：實證支持 final-architecture §2.2 採提案 C 的 E_eff（20% 硬上限＋T_flow 押金錨點信任流）。下一輪模擬換裝 E_eff 後，驗收判準：洗量 Agent 平均額度 ≤ 誠實 Agent。對應缺陷登記簿 P0-1 的參數定案工作。

### F-2（黃）：高違約情境下 2.5% 手續費蓋不住壞帳

high_default（15% 人口借滿後永久離線）壞帳率 2.92% > 費率 2.5%；Treasury 348 CC < 壞帳 406 CC，協議淨部位為負。信用額度政策有效限損（15% 跑路人口僅造成 2.92% 壞帳），但「壞帳 < 手續費」判準不過。

**處置**：需提案 C 的分層——風險費（對低信任對手加價）＋保險池，或動態費率。另注意還債週期在此情境拉長至中位 44 天（>30 天計費週期），顯示違約潮會拖慢全網信用循環。

### F-3（綠）：月底同日到期造成 ~20% 溫和跌價，無死亡螺旋

expiry_cliff 價格 0.85→0.68，成交率維持 92.5%。UC-03 到期折價曲線（含 min_margin 下限）＋錯開計費週期足以管理，無需價格管制。§14.4「到期崩價」風險降級為可管理。

### F-4（觀察）：起始信用 20 CC 是市場規模的綁定約束

「信用不足未發布需求」達結算量的 4–10 倍：長期超額消耗型 Agent 迅速觸頂信用額度後，其後缺口無法進入市場。這是保守起始額度的預期代價（Sybil 成本的另一面），但參數掃描需把 starter credit 與成長係數列為主變數——它直接決定網路可服務的需求比例，也對應提案 C 評審指出的「反作弊摩擦 vs 冷啟動」張力。

### F-5（觀察）：§27 閉環在人口層面成立

baseline 還債週期中位 17 天 < 30 天計費週期；期末仍有 ~58% Agent 處於負餘額，主要為結構性赤字人口（利用率 >1），符合模型設定而非機制失靈。
